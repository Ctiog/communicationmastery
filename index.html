⚙SETUP

Coach IA — API compatible OpenAI

Pour activer les réponses générées par IA, ajoute une clé API et un endpoint compatible. La clé est enregistrée uniquement dans le stockage local de ce navigateur. Ne l'utilise pas sur un appareil partagé. Les appels se font depuis le téléphone : l'hébergeur de cette application ne reçoit pas la clé.

Données et installation

La progression, les notes et les entrées du journal sont conservées sur cet appareil. Utilise l'export pour sauvegarder tes données.

Installer sur Android

Une fois l'application hébergée en HTTPS, ouvre son adresse dans Chrome, puis menu ⋮ → « Installer l'application » ou « Ajouter à l'écran d'accueil ». Le mode hors ligne conserve l'interface et le programme. Les appels au Coach IA nécessitent Internet.
